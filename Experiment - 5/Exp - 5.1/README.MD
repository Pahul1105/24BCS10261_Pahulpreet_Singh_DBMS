## Aim

To calculate the percentage of total revenue contributed by American Cuisine using conditional aggregation and round the result to 2 decimal places.

## Question

### Practice Problem - 4

Write a query to do the following:

* Find out what percentage of the total revenue (sum of all orders) is contributed by **American Cuisine**.
* Alias the percentage calculation function as `American_Revenue`.
* Round the final value to **2 decimal places**.

### Orders Table

The `Orders` table has the following fields:

| Column Name | Data Type     | Description                  |
| ----------- | ------------- | ---------------------------- |
| `order_id`  | INT           | Primary key                  |
| `item_name` | VARCHAR(255)  | Name of the ordered item     |
| `cuisine`   | VARCHAR(255)  | Cuisine of the ordered item  |
| `category`  | VARCHAR(255)  | Category of the ordered item |
| `price`     | DECIMAL(10,2) | Price of the order           |
| `status`    | VARCHAR(255)  | Status of the order          |

### Expected Output

| American_Revenue |
| ---------------- |
| 27.75            |

## SQL Queries Used

### Calculate American Cuisine Revenue Percentage

```sql
select ROUND((100*(SUM(case when cuisine= 'American' THEN price ELSE 0 END))/SUM(price)),2) 
AS American_Revenue FROM Orders;
```

## Output

```text
+------------------+
| American_Revenue |
+------------------+
| 27.75            |
+------------------+
```
